# Presentation deck (source)

The live deck is a Claude Slides artifact (private to its owner until shared from its Share menu; it exports to
PowerPoint and PDF): https://claude.ai/artifact/E7QcxyNRLH7yDeHx4geypf

This folder is a copy of its source for version control: `project/deck.json` (order, sections, fonts),
`project/deck.css` (shared styles) and one HTML file per slide under `project/slides/` (speaker notes in each
slide's `<aside>`). Images are the figures in `results/figures/`, uploaded to the artifact. Content follows
`docs/presentation_outline.md`; every number traces to Findings.md / results/master.csv.
