Leakage is the first thing examiners check. Removing identifier columns turned 95.5% of the dataset into exact duplicates - without de-duplication the same flow sits in train and test and accuracy is fake. DNS_QUERY_ID is a random transaction number that hid 131,000 duplicate benign flows. All attacks came from 4 of 40 source IPs, so IP columns would let a model memorise hosts. Our scores are therefore lower than published 91-93% figures, which keep the duplicates (F13) - but honest.
