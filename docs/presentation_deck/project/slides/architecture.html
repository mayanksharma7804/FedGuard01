ARCHITECTURE

Three tiers, one new aggregation rule

CLIENT TIER

Each organisation

Same CNN-LSTM, its own non-IID data, DP-SGD (Opacus). Sends update + declared settings.

AGGREGATION TIER · FEDGUARD

Noise-aware AutoGM

R1 centre’s noise counted · R2 quadrature residual · R3 robust allowance (median + 2 MAD) · R4 noise-length tolerance · floor on the allowance

DISTRIBUTION TIER

New global model

Sent back to every organisation; the round repeats.

Pure NumPy aggregator: the same code runs in our engine and in Flower (results agree to 6.9e-17).

The aggregator is the contribution. R1: the centre is built from noisy updates too, so its noise is counted. R2: the quadrature residual. R3: the allowance for normal non-IID spread is computed from the cleaned residuals, not raw distances. R4: forgive the natural wobble of a large noise length. The floor stops the allowance collapsing to zero when most residuals are hidden by noise (F48). These settings were chosen on the validation split before any test result (F50).
