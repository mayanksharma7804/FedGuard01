Federation is free with IID data; non-IID data and DP cost mostly the rare attack classes (F22, F29, F38)

Federation itself costs nothing with IID clients - FedAvg reaches the centralised ceiling. Non-IID data costs up to 0.16 macro-F1, mostly rare classes held by one small client. Record-level DP roughly halves macro-F1 even at epsilon 8: with 1-19k rows per client and 40k parameters the noise is about ten times the clean update, so rare classes drown first. Attack-versus-benign detection mostly survives (binary F1 0.80-0.85), which is why we report both.
