FOUNDATION · EXPERIMENT E0

Can the server predict the noise? Yes, to about 1%

Measured / predicted = 1.000-1.005 over 150 pairs · noise at 90° to the update (cos ≈ −0.005) · E0 first caught a 5-20% error in our formula (F34, F35)

E0 trains the same client twice from the same model with the same batches and dropout - once with noise multiplier sigma, once with zero - and compares the measured noise with the declared radius. It matched to within about 1 percent for every sigma and step count, and the noise is orthogonal to the signal, which justifies the quadrature rule. Importantly, E0 was not a formality: its first run showed our radius was 5-20% too small, because Opacus samples with rate 1 over ceil(n/B) and divides by an integer batch size. Fixed before any baseline was run.
