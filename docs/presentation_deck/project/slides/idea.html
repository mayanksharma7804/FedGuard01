OUR CONTRIBUTION

FedGuard: forgive exactly the noise each client declares

r = lr · σ · C · √(T · d) / B

1 · DECLARE

Each client reports its DP settings (σ, C, B, T, lr) with its update.

2 · PREDICT

The server computes the noise radius r the client’s update must carry.

3 · JUDGE THE REST

Trust is set by the part noise cannot explain: √(distance² − r²).

Two facts about noise in high dimension make this work. First, the length of random noise is almost fixed: about sigma times the square root of d. Second, it is almost exactly at 90 degrees to any fixed direction, such as the true update, so Pythagoras applies: distance squared equals true difference squared plus noise squared. That is the quadrature rule. The radius formula: each DP-SGD step adds lr times Gaussian noise of size sigma C over B; T independent steps add up like a random walk, hence the square root of T.
