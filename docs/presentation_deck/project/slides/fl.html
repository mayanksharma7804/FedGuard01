THE STANDARD ANSWER

Federated learning: share the lesson, not the data

STEP 1

Server sends the global model

The same detector to every organisation.

STEP 2

Each trains on its own logs

Raw data never leaves the building.

STEP 3

Server combines the updates

FedAvg: a weighted average. Then repeat.

Each round sends only an update - the change to the model weights - never a single log line.

One round: the server sends the global model, every organisation trains it locally for a few epochs, sends back only the weight change, and the server averages these changes. After 30-50 rounds the model is good for everyone. In our project: 5 or 10 organisations, a CNN-LSTM detector with 40,266 parameters, 5 local epochs per round.
