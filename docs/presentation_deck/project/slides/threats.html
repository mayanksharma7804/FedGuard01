TWO WELL-KNOWN THREATS

Updates leak, and members can lie

LEAKS → DIFFERENTIAL PRIVACY

Updates can be inverted

Training records can be rebuilt from an update. DP-SGD clips each record’s influence and adds calibrated noise; ε measures the privacy.

LIES → ROBUST AGGREGATION

Updates can be poisoned

A compromised member can teach the model to ignore attacks. AutoGM trusts updates close to the crowd and down-weights the rest.

Our review of 25 intrusion-detection studies: none uses both defences together.

Leaks: "Deep Leakage from Gradients" showed records can be reconstructed from updates; the fix is differential privacy - smaller epsilon means more noise and more privacy. Lies: Byzantine clients send poisoned updates; the fix is a robust aggregator such as AutoGM, an auto-weighted geometric median. Our scoping review found that no IDS framework in the 25 studies uses both.
